# نظام تشغيل الإدارة الاجتماعية — مؤسسة مرسال

تطوير نظام إدارة بيانات وتقارير الإدارة الاجتماعية إلى **نظام تشغيل كامل**: من إضافة القرار الاجتماعي، إلى تأكيد البيانات، والإرسال ضمن دفعة الصرف، والتحويل، ومتابعة الاستلام، والاسترداد، حتى انتهاء مدة الاستحقاق والتجديد. كل عملية تُسجل باسم القائم بها وتاريخ ووقت تسجيلها.

## التشغيل

| الطريقة | الخطوات |
|---|---|
| ملف واحد | افتحي `dist/social-system.html` في المتصفح. يعمل في **الوضع المحلي**: البيانات في هذا المتصفح فقط. |
| GitHub Pages | Settings ← Pages ← Branch `main` / root. يعمل أيضاً في الوضع المحلي. |
| صفحة claude.ai مشتركة | انشري `dist/artifact.html` مع خاصيتي `db` و`user`. البيانات مشتركة بين كل الفريق وكل مستخدم يُعرف باسمه. |

للتجربة: من «الإعدادات» اضغطي «تحميل بيانات تجريبية» (28 حالة وهمية بأربعة موظفين وهميين).

## الشاشات

| الشاشة | ماذا تفعل |
|---|---|
| لوحة المتابعة | تنبيهات (تأكيد بيانات، معلّق، متأخر، تجديد، منتهي، استرداد) + مؤشرات التشغيل والمالية والخدمات والموظفين + اتجاه 6 شهور |
| مهامي | ما هو مطلوب من الموظف الآن ومؤشراته الشخصية |
| الحالات | MASTER موحد: بحث، تصفية، ملف الحالة (القرارات، الاستحقاقات، التحويلات، الاستردادات، العمليات، سجل تعديل البيانات) |
| القرارات | إضافة سريعة (كود + اسم + خدمة + مدة + بداية + نهاية)، منع التعارض، تجديد، إيقاف/سحب |
| دورة الصرف | توليد الاستحقاقات، مراحل كل حالة، تأكيد البيانات، إرسال جماعي في دفعة، تسجيل التحويل، اعتماد المعلّق |
| المتابعة | لم يرد / رد وتم الصرف / رد ولم يتم الصرف (سبب + إجراء)، 3 محاولات |
| الاستردادات | كلي/جزئي، ربط بالتحويل، صافي المصروف، التسوية |
| التجديد والانتهاء | قبل النهاية بشهرين، إرسال للتجديد، الإغلاق |
| توزيع المهام | مهام تلقائية من دورة العمل + يدوية، إسناد جماعي، متأخرات، إرجاع للتصحيح |
| العمليات | سجل موحد لكل إجراء (تلقائي ويدوي) بالمنفذ ووقت التسجيل |
| التقارير | شهري، موظفين، كل العمليات، مقارنة الشهور · تصفية بالشهر والموظف والخدمة وحالة القرار والمحافظة والجنسية · تصدير CSV ونسخ للإكسل |
| سجل التدقيق | كل إجراء وكل تعديل بالقيمة القديمة والجديدة |
| الإعدادات | قواعد التشغيل، الإسناد التلقائي، المستخدمون والأدوار، أنواع الخدمات، النسخ الاحتياطي |

## التوافق مع النظام الحالي

النسخة الحالية محفوظة في `legacy/social-system-v1.html`. النظام الجديد يقرأ نفس المجموعات (cases, decisions, lines, ents, ops, audit) بدون حذف أو تغيير أي حقل، ويضيف مجموعات جديدة فقط. يمكن تحديث صفحة v1 بهذا الكود مباشرة فتظهر كل البيانات القديمة.
